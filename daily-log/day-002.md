## 📚 What I Learned

### 1. Creating a Server with Node.js

* Node.js provides the built-in `http` module.
* `http.createServer()` creates an HTTP server.
* The server receives:

  * `req` → incoming request
  * `res` → response to the client
* Routing can be handled manually using:

  * `req.method`
  * `req.url`

Example:

```js
const http = require("http");

const server = http.createServer((req, res) => {
    if (req.method === "GET" && req.url === "/") {
        return res.end("Home Page");
    }

    res.end("Route Not Found");
});

server.listen(3000);
```

---

### 2. Why Express.js?

With pure Node.js, we have to manually handle:

```text
HTTP Method
    +
URL
    ↓
Conditional Logic
    ↓
Handler
    ↓
Response
```

As the application grows, this can become difficult to maintain.

Express provides higher-level abstractions for building web servers and APIs.

---

### 3. Express.js Application

```js
const express = require("express");

const app = express();
```

`express()` creates an **Express application**.

The `app` object provides methods such as:

```js
app.get()
app.post()
app.listen()
```

---

### 4. Express Routing

Instead of manually checking:

```js
req.method
req.url
```

Express allows us to define routes directly:

```js
app.get("/", (req, res) => {
    res.send("Home Page");
});

app.post("/users", (req, res) => {
    res.send("User Created");
});
```

Express matches the incoming request with the registered route and executes its handler.

---

## 🔥 5. How Express is Built on Node.js

Express does **not replace Node.js**.

It provides a higher-level abstraction on top of Node.js HTTP functionality.

Conceptually:

```text
Node.js
   ↓
HTTP Module
   ↓
http.createServer()
   ↓
Express Application
   ↓
Routing + Middleware + Request/Response Helpers
```

---

### 6. Understanding `app.listen()`

When we write:

```js
app.listen(3000);
```

Express internally uses Node.js HTTP server functionality.

Conceptually:

```js
const server = http.createServer(app);

server.listen(3000);
```

So:

```text
app.listen()
     ↓
Node.js HTTP Server
     ↓
Listen for incoming requests
```

## 🧠 Key Takeaways

* Node.js provides low-level HTTP functionality.
* `http.createServer()` creates the HTTP server.
* Express is built on top of Node.js.
* Express simplifies routing and request handling.
* `app.get()` handles GET routes.
* `app.post()` handles POST routes.
* `app.listen()` connects the Express application to the Node.js HTTP server.
* Express **doesn't replace Node.js**; it provides abstractions on top of it.
