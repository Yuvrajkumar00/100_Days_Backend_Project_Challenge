## 📚 What I Learned

### 1. What Problem Does Node.js Solve?

* Allows JavaScript to run **outside the browser**.
* Makes JavaScript useful for backend/server-side development.

### 2. What is Node.js?

* Node.js is a **JavaScript runtime environment**.
* It uses **V8** to execute JavaScript.
* It also provides runtime APIs such as `fs`, `http`, `crypto`, `process`, etc.

### 3. 🔥 Why Does Node.js Run JavaScript?

* V8 is a JavaScript engine developed by Google.
* Node.js uses V8 to parse, compile and execute JavaScript code.

### 4. 🔹 What Happens When Node.js Runs a JavaScript File?

```text
app.js
   ↓
Node.js
   ↓
Module Wrapper
   ↓
V8
   ↓
JavaScript Execution
```

Node.js wraps the module code inside a function before executing it.

### 5. 🧩 What Does the Wrapper Provide?

The CommonJS module wrapper provides:

```js
(function (exports, require, module, __filename, __dirname) {
    // code
});
```

It provides:

* `exports`
* `require`
* `module`
* `__filename`
* `__dirname`

### 6. Node.js Runtime + Module Wrapper

```text
Node.js Runtime
│
├── V8
├── Runtime APIs
│   ├── fs
│   ├── http
│   ├── crypto
│   └── process
│
└── CommonJS Module System
    ├── require()
    ├── module.exports
    └── exports
```

### 7. 🌐 What About the Browser?

* Browser JavaScript runs inside a browser environment.
* Browser does **not** provide Node.js APIs like `fs`.
* Browser also doesn't provide CommonJS variables such as `require` and `module` by default.

## 📦 CommonJS — Export & Import

### 🔹 Export

#### Single Export

```js
// math.js
const add = (a, b) => a + b;

module.exports = add;
```

#### Multiple Export

```js
// math.js
const add = (a, b) => a + b;
const subtract = (a, b) => a - b;

module.exports = { add, subtract };
```

Can also use:

```js
exports.add = add;
exports.subtract = subtract;
```

### 🔹 Import

#### Import a Single Export

```js
const add = require("./math");
```

#### Import Multiple Exports

```js
const { add, subtract } = require("./math");
```

#### Import Using a Different Name

```js
const { add: addition } = require("./math");
```

#### Import Everything

```js
const math = require("./math");

math.add(2, 3);
math.subtract(5, 2);
```

## 🧠 Key Takeaways

* **Node.js = JavaScript Runtime**
* **V8 = JavaScript Engine**
* **Node.js ≠ only JavaScript runtime** → Deno and Bun are also runtimes.
* **Module Wrapper** provides CommonJS variables.
* `module.exports` → exports data from a module.
* `require()` → imports a module.
* `exports.name = value` → adds a property to the exported object.
* `module.exports` can export **one value or multiple values as an object**.
