## Day 013 – Todo Update & Delete Functionality

**Date:** 01 October 2026
**Project:** Todo Backend API
**Focus:** Implementing Update and Delete Todo controllers

### Topics Covered

* Updating an existing Todo using `findOneAndUpdate()`.
* Implementing partial updates using the PATCH method.
* Filtering undefined values from the request body.
* Checking Todo ownership using `createdBy`.
* Preventing updates to soft-deleted Todos.
* Implementing the `deleteTodo` controller.
* Handling cases where a Todo does not exist.

### Project Implementation

* Created the `updateTodo` controller.
* Created the `deleteTodo` controller.
* Added user-specific access checks to Todo operations.
* Implemented validation for empty update requests.
* Used an allowlisted object to control which fields users can update.
* Handled successful updates and Todo-not-found responses.

### Key Learnings

* Difference between PUT and PATCH.
* How `findOneAndUpdate()` works.
* Why ownership checks are important in backend APIs.
* How to prevent unauthorized users from modifying another user's resources.
* Why we should not directly pass `req.body` into database update operations.
