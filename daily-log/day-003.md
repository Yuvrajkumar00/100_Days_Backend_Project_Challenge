### 2. MongoDB Connection

Understood the difference between:

* **MongoDB Server** → Actually stores and manages the database.
* **MongoDB Compass** → GUI tool used to view and manage MongoDB databases.
* **MongoDB Atlas** → Cloud-hosted MongoDB database.

Important understanding:

```text
Backend API
    ↓
MongoDB URI
    ↓
MongoDB Database
```

MongoDB Compass is only a tool to interact with the database. It does not itself run the MongoDB server.

### 3. Local MongoDB vs MongoDB Atlas

Learned that:

```text
mongodb://localhost:27017/mytodoapp
```

requires MongoDB Server to be installed and running locally.

Whereas:

```text
mongodb+srv://<username>:<password>@<cluster>/mytodoapp
```

connects the application to a MongoDB Atlas database.
