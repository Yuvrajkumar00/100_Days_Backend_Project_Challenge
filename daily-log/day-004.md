# Day 004 — Todo Backend Foundation

## 📅 Date

22 September 2026

## 🎯 Goal

Build the foundational structure of the Todo backend and prepare the reusable utilities and middleware required for the application.

---

## 📚 What I Learned

### 1. Database Models

Created the initial models for:

* User
* Todo

Learned how to structure relationships between users and their todos.

### 2. Constants

Created a constants file for fixed application values such as:

* User roles
* Todo status
* Todo priority

### 3. API Error Handling

Created `ApiError` to provide a consistent structure for application errors.

### 4. API Response

Created `ApiResponse` to maintain a consistent API response structure.

### 5. Async Handler

Created an `asyncHandler` utility to handle errors from asynchronous controller functions.

### 6. Global Error Handler

Created centralized error-handling middleware so application errors can be handled in one place.

### 7. Validator Middleware

Created validation middleware to validate incoming API requests before they reach the controller.

### 8. Multer Middleware

Created Multer middleware for handling multipart/form-data and preparing the project for file uploads.

## 🔄 Backend Request Flow

```text
Client
  ↓
Route
  ↓
Validation Middleware
  ↓
Authentication / Other Middleware
  ↓
Controller
  ↓
Database
  ↓
Response
  ↓
Global Error Handler
```

---

## 💡 Key Takeaway

Today I focused on building the **foundation of the backend instead of directly writing CRUD APIs**.

I learned that a scalable backend should separate responsibilities between:

* Models
* Middleware
* Controllers
* Utilities
* Error handling
* Validation

The goal is to make the codebase easier to understand, maintain, and extend as the project grows.
