## 🔐 Authorization Concept

Todos are associated with the authenticated user through:

```js
createdBy: req.user._id
```

For fetching a specific Todo:

```js
Todo.findOne({
    _id: id,
    createdBy: req.user._id
});
```

This ensures the Todo belongs to the currently authenticated user.

## 🧠 Key Learning

Authentication tells us **who the user is**.

Authorization determines **which resources that user is allowed to access**.

For this Todo API, I am enforcing ownership at the database query level.
