## 🎯 Today's Goal

Implement the **Change Password** functionality and understand how password changes interact with existing authentication sessions.

## 📝 Planned Flow

```text
Get user from req.user
        ↓
Get old & new password
        ↓
Verify old password
        ↓
Hash new password
        ↓
Update user password
        ↓
Save user
        ↓
Find session
        ↓
Revoke session
        ↓
Send password changed email
        ↓
Send response
```

## 🧠 Key Learning

**Password controls future authentication, while tokens/sessions control existing authentication.**

Changing a password and revoking an existing session are separate operations with different purposes.
