# 📌 Challenge Principles

### 01 — Build > Watch

Tutorials are useful, but implementation comes first.

### 02 — Understand > Memorize

I want to understand concepts well enough to explain them in my own words.

### 03 — Projects > Random Code

Whenever possible, every major concept will be connected to a real implementation.

### 04 — Document Everything Important

I will document:

* What I learned
* What I built
* What broke
* How I fixed it
* What I still don't understand

A bad coding day is better than giving up on the journey.

### 06 — Proof > Claims

Instead of saying:
